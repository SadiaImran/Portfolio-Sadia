## 🌟 Overview
A modern, responsive personal portfolio showcasing full-stack web applications, real-time AI agents, microservices architectures, and technical credentials.

### ✨ Key Features
- **Responsive Modern UI:** Tailored editorial dark/light aesthetics with Berry Rose accents and frosted-glass topbar.
- **Interactive Project Showcase:** 7 in-depth projects with modal dialogs, tech stacks, GitHub links, and live demos.
- **Comprehensive Tech Stack:** 52 verified skills across Frontend, Backend, AI/ML, Cloud & DevOps, Databases, and Architecture.
- **Verified Credentials:** Interactive certified credential preview for Generative AI & Full-Stack engineering.
- **Integrated CV Viewer:** Privacy-conscious interactive PDF reader powered by Google Drive.

---

## 🛠️ Built With
- **HTML5 & Semantic Markup**
- **Modern Vanilla CSS3** (CSS Grid, Flexbox, CSS Variables, Glassmorphism)

- **Lucide & Official Brand Icons**

## 💻 Local Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/SadiaImran/Portfolio-Sadia.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Portfolio-Sadia
   ```
3. Open `index.html` in any modern web browser or launch with VS Code Live Server.
